## How to use this guide

1. Read [M · Maths the course assumes](maths.md) once. Do every "Your turn".
2. Work the units in the order of the [ranking](inventory.md): the hardest, most-asked types first. Inside a unit: read the idea, do the tiny example, then the stepper (do each step before revealing it), then the "Do it cold" questions with the solution closed.
3. Only leave a unit when you can tick its checklist at the bottom.
4. Print the [cheat sheet](cheatsheet.md) and run the [battle table](battle.md): every past question solved with the sheet alone.
